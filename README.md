### Emergency Response Route Planner

A full-stack emergency-dispatch simulation that models the decisions an operations center has to make in real time: which ambulance to send, the fastest route to take, and which hospital to route a patient to. The routing engine represents the response area as a weighted graph and uses **A\* search** to compare travel times across available ambulances, then tracks each incident through its full lifecycle (dispatched → arrived → transport → resolved).

### LVN Atlas

A migration-intelligence concept aimed at helping people understand the financial and lifestyle impact of relocating before they move. The project is currently in the product-discovery phase — the repo consists of a documented domain model, ER diagram, user personas, user flows, and user stories written to define the system before writing implementation code.
